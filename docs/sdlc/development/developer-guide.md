<!-- sdlc:auto:start overview -->
RAG app is a full-stack scaffold generated by the Quorq AI SDLC platform, consisting of a React 19 + Vite SPA frontend running on seeded sample data and a FastAPI 0.115 backend that currently ships only a health check. The backend uses SQLAlchemy with a SQLite default (Postgres 16 available via Docker Compose), Pydantic schemas, and stub routers. The frontend includes Vitest component tests, Playwright e2e tests, ESLint, and Prettier.
<!-- sdlc:auto:end overview -->

<!-- sdlc:auto:start prerequisites -->
- Node.js 20+
- Python 3.12
- Docker and Docker Compose (for Postgres/Minio services)
<!-- sdlc:auto:end prerequisites -->

<!-- sdlc:auto:start setup -->
1. cd frontend && npm install
2. cd backend && pip install -r requirements.txt
3. docker compose up -d  # optional: start Postgres and Minio for the approved stack
<!-- sdlc:auto:end setup -->

<!-- sdlc:auto:start conventions -->
- Frontend uses path alias @/* mapped to ./src/*
- Backend follows one router per architecture component; routes return typed StubResponse placeholders until implemented
- Backend uses SQLite by default; set DATABASE_URL to switch to Postgres or another database
- CORS allows dev origins localhost:5173 and 127.0.0.1:5173 by default; override with ALLOWED_ORIGINS env var
- Backend tables created via Base.metadata.create_all on startup; no Alembic migrations yet
- Frontend screens render seeded sample data; api.ts is the seam for wiring real endpoints
- Backend runs as unprivileged user in Docker with a Python-based healthcheck
- Vitest component tests are scoped to src/** and run in jsdom; Playwright specs live in e2e/
<!-- sdlc:auto:end conventions -->

<!-- sdlc:auto:start troubleshooting -->
| Problem | Solution |
|---|---|
| Frontend API calls blocked by CORS | Ensure ALLOWED_ORIGINS env var includes the frontend origin, or run frontend on localhost:5173 which is allowed by default |
| Backend cannot import app when running pytest | Run pytest from the backend/ directory; pytest.ini sets pythonpath=. so imports resolve correctly |
| Playwright e2e tests fail without a browser | Run npm run test:e2e:install to fetch Chromium first |
| Backend defaults to SQLite file app.db instead of Postgres | Set DATABASE_URL environment variable to the Postgres connection string and restart the service |
